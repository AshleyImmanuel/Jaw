# Jaw Vision

## Mission
Jaw is a production-grade cross-platform UI runtime that enables developers to preserve their UI investment.
Developers should build once, then target Web, Android, iOS and Desktop without rewriting their interface.

## Beta 1 Objective
Validate the architecture by building:
- Compiler
- Runtime
- Universal Component Tree
- Layout Engine
- Styling Engine
- Web Renderer
- CLI
- Hot Reload

## Out of Scope
Android, iOS, Desktop, AI migration, plugins, advanced animations.
